# Telepítési útmutató – C# WPF alkalmazás

Ez a dokumentum bemutatja, hogyan tudod telepíteni és elindítani a WPF alkalmazást Windows rendszeren.

## Rendszerkövetelmények
- Windows 10 vagy újabb
- .NET Desktop Runtime (ha a telepítő nem tartalmazza)
- Admin jogosultság a telepítéshez (ajánlott)

---

## Telepítés lépései

### 1. Telepítő letöltése
Töltsd le a legfrissebb telepítő fájlt (`.exe`) a megadott forrásból (pl. weboldal, GitHub, vagy küldött link).

---

### 2. Telepítő indítása
- Kattints duplán a letöltött `.exe` fájlra
- Ha a Windows biztonsági figyelmeztetést jelenít meg, válaszd a **Futtatás** opciót

---

### 3. Telepítési hely kiválasztása
- Válaszd ki a telepítés helyét (alapértelmezetten ajánlott útvonal is használható)
- Opcionálisan módosíthatod a mappát

---

### 4. Asztali ikon beállítása
- Döntsd el, hogy szeretnél-e asztali ikont
  - ✔ Igen: könnyebb elérés az alkalmazáshoz
  - ✖ Nem: csak a Start menüből lesz elérhető

---

### 5. Telepítés indítása
- Kattints az **Install / Telepítés** gombra
- Várd meg, amíg a folyamat befejeződik

---

### 6. Befejezés és indítás
- A telepítés végén kattints a **Finish / Befejezés** gombra
- Ha van ilyen opció, pipáld be az **„Alkalmazás indítása”** lehetőséget
- Indítsd el az alkalmazást

---

## Hibaelhárítás
- Ha nem indul el az alkalmazás, ellenőrizd, hogy telepítve van-e a .NET Desktop Runtime
- Próbáld meg rendszergazdaként futtatni az alkalmazást
- Győződj meg róla, hogy a telepítés sikeresen lefutott

---

## Támogatás
Ha problémád van a telepítéssel, vedd fel a kapcsolatot a fejlesztővel vagy a támogatási csapattal.
